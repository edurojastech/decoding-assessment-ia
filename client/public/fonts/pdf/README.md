# Fontes do PDF da devolutiva

Aileron (Light, Regular, SemiBold, Bold) convertida de `.otf` (contornos CFF) para `.ttf` (TrueType),
porque o jsPDF só incorpora fontes TrueType. Mesmo desenho das fontes em `../`, licença SIL OFL.
Usadas por `client/src/lib/pdf.js` para gerar o PDF com texto selecionável.
